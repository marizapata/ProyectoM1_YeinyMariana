# Generador de Paletas

Aplicación web interactiva que permite generar paletas de colores aleatorias de forma dinámica.

Proyecto Integrador - Módulo 1 Full Stack | Soy Henry


## Funcionalidades

- Generación aleatoria de colores HEX
- Selección de cantidad de colores
- Render dinámico de paletas
- Microfeedback visual
- Accesibilidad básica


## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Pages
